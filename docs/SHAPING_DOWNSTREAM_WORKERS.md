# Downstream native workers

`shaping_rescue_worker.py register --execution-kind outer` and
`--execution-kind variant` seal the original outer/variant admission inputs in
the bounded worker transport. Variant registration also requires
`--human-qualification`. These are transports for the existing native owners;
they do not select finalists, change source boundaries or admit incomplete fits.

Freeze public policy snapshots before generating outer decisions. Registration
captures evidence actually read by the original admission owner, source modules,
command templates, binary identities and the approved CPU budget. The existing
384 MiB input allowance, four approved workers, no-overwrite transfer, RAM/SSD
admission and per-fit CPU claims remain in force. A worker reruns admission and
compares its exact resolution before claiming a CPU or creating an attempt.
Existing attempts cannot be replayed.

The controller tests cover terminal receipts for unshaped, frozen-pretrained and
joint-pretrained outer/variant branches. Transport tests cover evidence drift,
schema/stage mismatch and rejection before CPU admission. They do not establish
scientific fit completion or a full fleet deployment.

Downstream assignments also bind the exact worker request. Collection reruns
the original admission owner using the recorded approved host, resolves
conditional fresh-control identities through that gate, and checks the full
selected phase schedule. Every phase must retain its complete epoch inventory,
native terminal receipt, binary identity and final model hash. The controller's
exposure must equal the sum of admitted phases; variant role names resolve to
their admitted model family. The existing primary/rescue collection checks are
unchanged. Pack, unpack and atomic import coverage includes paired pretrained
phases; it does not establish a real downstream scientific fit. Evaluation
deployment still requires separate qualification before launching a wave.

The evaluation transport has an explicit `--later-only` observer mode for
collected outer, matched fresh-control and generalization fits. It reproduces
`outer_context`, binds the admitted family/representation and schedule, and
pins only the registered final checkpoint. Outer responses are never used for
checkpoint diagnosis. Execution delegates to `later_sweep` with an explicit
cell filter; repaired representations use its existing re-export path rather
than the primary supplemental evaluator. A terminal export requires the saved
final report and completion marker, or the actual failed native gate plus its
explicit failure receipt. Import preserves the report's outer-evaluation scope
and admission identity. Cross-host later evaluation is not enabled.

Transport/controller checks use fixture artifacts and native-owner mocks;
they establish routing, artifact preservation and refusal behavior. A live
outer or variant admission, real worker evaluation and verified result import
are still required to establish scientific execution.

After corrected-threshold activation, new pretrained rescue, outer and variant
fits require the registered corrected native BUILD. Capsule admission and native
execution both check this binding before creating a fit. Unchanged control
families retain their separately qualified runtimes. Historical fits stay
preserved. The stale-build refusal checks cover all three execution owners,
including a human-only role that resolves to a pretrained family; they launch
no trainer and create no attempt directory.
# Native phase memory bounds

CPU/RAM admission use the same resource helper: 4 GiB if any registered native
phase runs for 480 epochs, otherwise the existing 2 GiB neural bound. Extension
and non-neural control owners retain their existing 4 GiB bound. A controller's
systemd cap must cover its child scope; a child requesting more memory cannot
escape an enclosing smaller cgroup. This resource correction changes no phase
length, pairing, optimizer or selection gate.

## Resumed dispatch and local collection

A matched fresh control resolves the full evidence closure only for its owning fold. The other fold admissions are inspected as metadata to reject duplicate identities. This retains the two-GiB worker limit.

A pretrained finalist can use a joint parent from an inactive family only when the admission already pins that parent's complete base-decision evidence and the original native candidate gate verifies its RUN. Each worker request pins the resulting parent RUN bytes. The frozen admission, selected setting and training budget remain unchanged.

When the coordinator also trains, use shaping_local_collection.py for its successful terminal fits. It verifies the frozen request, native terminal gates and file inventory before sealing a local collection receipt; it does not transfer or restart the fit.


## Autonomous completion

The resumed dispatch uses persistent services and frozen source exports. Variant stages preserve already registered requests, split launches by their original source identity, and reuse complete submission receipts. Partial or conflicting submissions remain explicit failures; no failed fit is silently restarted.

shaping_resume_supervisor.py collects the finite 217 new deliveries (214 remaining core cells and three registered matched controls). shaping_legacy_delivery.py reconciles the 35 existing outer-fold-2 deliveries. Four host-scoped final evaluators and a final-only continuation evaluator preserve the original score gates. shaping_archive_once.py validates each closed result and performs durable checksum readback once.

shaping_autonomous_finish.py advances the registered 25 uncertainty analyses and 48-model cost workflow only after their artifact prerequisites exist. It records commands before launch, preserves failures, and writes a readiness receipt after computational and archive closure. Scientific interpretation and the complete-study claim remain separate. The cost preparation can use shared coordinator data directly, preserving the existing transport-capsule limits. Continued-run training resources retain separate observed clocks and leave unavailable aggregate time/RSS values null.

The controller checks metadata once per minute and retires its metadata watchers after all registered deliveries, final panels, analysis receipts and durable archives close. The snapshot watcher uses the worker's verified trim receipt when worker and coordinator share the same directory, avoiding a second trim. Four recovered conditional extension results are included explicitly in archive closure. The study-owned archive mount can recover stale NFS handles; checksum failures remain hard failures.
