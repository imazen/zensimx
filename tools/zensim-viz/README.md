# zensim A explorer

A browser feature atlas, PDP/ICE lens and per-weight audit for the shipped
revision-7 A bake. The Function exhibit explains its max pair, complete affine
background, output calibration and structural limits. Every input links to its
registry formula and detector explanation.

Images stay in the browser. The default pair is generated by code; no sample
photos ship. Browser decoding is labelled sRGB8, not zenjpeg. HDR is a TRAIN
feature bank, not a browser HDR pixel path.

[PAGES.md](PAGES.md) describes the compact banks, single IMIJ-set, scientific
gates and dispatch-only deployment boundary. [REPORT.md](REPORT.md) records
measured bytes, parity, browser times and captures. The coordinator installs
the prepared workflow in imazen/zensim after owner review; this tool does not
enable Pages or dispatch it.

Serve a prepared directory with `just viz-serve /absolute/prepared/site`.
Source lives in `pages/`; generated Wasm, bakes, data and screenshots stay
outside git. `web/design/` remains the supplied design directory, verbatim.

The native exporter and historical numeric/browser gates remain available.
The previous static viewer is preserved with its frozen review artifacts;
its runtime was retired from git after the A replacement passed. Historical
browser checks accept `VIZ_URL` for that preserved viewer.
